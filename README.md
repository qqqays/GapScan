# GapScan

GapScan 是一个自动化的开源需求与痛点雷达，帮助开发者从 GitHub 社区中发现值得关注的功能缺口。

项目计划每天监控 GitHub Trending 项目和高互动的 Feature Request，再使用大模型分析需求与项目现有能力，筛选出社区呼声较高、但尚未被解决的机会。

## 为什么是 GapScan

GitHub Issue 中往往隐藏着真实且持续的用户需求，但人工逐个阅读热门项目的 Issue 成本很高。GapScan 试图把这类信息整理成可筛选的机会报告，帮助开发者判断：

- 哪些需求获得了较多社区关注
- 需求是否已经被项目现有功能覆盖
- 哪些问题可能适合做成开源项目、插件或独立产品

## 工作流程

```text
GitHub Trending
      |
      v
热门项目与高互动 Feature Request
      |
      v
读取项目 README 与相关上下文
      |
      v
LLM 分析需求是否已被满足
      |
      v
输出结构化 Gap 报告
      |
      v
本地查看或通过 Webhook 分发
```

## 核心功能

- **自动扫描**：按计划获取 GitHub 热门项目及高互动 Feature Request。
- **需求分析**：使用大模型理解 Issue 内容，并判断需求是否已由项目现有能力覆盖。
- **机会筛选**：聚焦社区关注度高、但仍未被满足的功能缺口。
- **结构化输出**：将分析结果整理为便于阅读和后续筛选的机会报告。
- **结果分发**：支持本地查看，并计划支持通过 Webhook 发送通知。

## 报告示例

GapScan 的目标输出类似下面的结构：

```text
项目：example/project
需求：支持通过配置文件管理多环境部署
社区信号：Issue 获得较多评论与反应
当前状态：项目 README 未说明已支持该能力
机会判断：存在明确的用户需求，可进一步验证实现成本与目标用户
来源：https://github.com/example/project/issues/123
```

以上内容仅用于说明报告格式，不代表 GapScan 当前已经扫描或验证了该项目。
