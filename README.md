# GapScan 🔍

**GapScan** 是一个自动化的开源“需求与痛点雷达”。

它通过每天监控 **GitHub Trending** 榜单项目，利用 AI 深度分析那些未被解决的 **High-Reaction Issues**（高互动用户需求）。它的核心价值是帮你自动找出社区中**呼声极高、但项目目前尚未支持的功能缺口（Gap）**，帮你精准捕捉下一个极具开发价值的开源或独立变现机会。

### 🚀 核心功能

* **自动扫描**：每日定时爬取 GitHub 热门项目及高互动 Feature Request。
* **智能比对**：用大模型（LLM）比对项目 README，剔除已实现功能，精准锁定未满足的痛点。
* **机会分发**：结构化输出“绝对真空需求”报告，支持本地查看或 Webhook 通知。
